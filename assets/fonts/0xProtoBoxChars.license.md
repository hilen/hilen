# 0xProtoBoxChars.ttf

0xProto Nerd Font Regular 2.502, Nerd Fonts 3.5.1, cut down with `hb-subset` to
ASCII and the box chars U+2500 to U+257F, for the `Markdown box chars` UI test.

- Font: 0xType Project Authors, https://github.com/0xType/0xProto
- Patch: Nerd Fonts, https://github.com/ryanoasis/nerd-fonts
